# 戦闘フィードバックと個人成績

## 命中・撃破・アシスト

戦闘は60Hzの固定ステップで進む。各tickで攻撃対象と発射を先に確定し、既存の参加者順でダメージを適用する。シールドまたはHPが減ったときだけ命中が成立する。同tickに複数の攻撃が成立する場合も、対象のHPを0にした有効ダメージの攻撃者にキル、対象にデスを1回記録する。HPが0になった対象への後続ダメージは命中や成績に数えない。相互撃破は成立する。

被弾した参加者に、それまで有効ダメージを与えた相手のIDを保持する。撃破時には、とどめを刺した参加者と同チームの攻撃者に、本人を除いて各1アシストを付与する。同じ参加者による繰り返しの攻撃は1人分にまとめる。復活しても確定済みの成績は維持する。

履歴は撃破時、または自然回復でシールドかHPが実際に正の量だけ増加した最初の処理で消去する。回復量に小数がある場合も増加した時点を使う。回復可能になっても満タンで増加量が0なら履歴を保持する。同じtickではダメージを先に処理するため、回復直前の追撃は履歴に含まれる。特殊バリア、味方からの回復、支援能力は個別の貢献条件と併せて今後定義する。

## 占領と貢献ポイント

占領が完了したときに設置者へ20ptを付与し、設置者の占領成功数を1加算する。設置者が途中で離れたり撃破された場合も、ラウンド内の参加者IDで帰属を維持する。装置の設置時に設置者IDを必ず記録するため、有効な設置が完了した場合は常に帰属先がある。

占領が進んだ各tickについて、範囲内にいる同チームの生存参加者でそのtickの寄与を等分する。敵と係争している間や、味方が不在で進行が止まっている間は加算しない。成功した場合に限り、積み上げた寄与の比率で80ptを配分する。設置者も維持に参加できる。放棄された装置やラウンド終了時に未完了の装置は報酬を確定しない。

各進行tickを60の整数単位に分ける。1〜5人での等分が整数になり、途中参加を含めて固定ステップで再現できる。配点の最小単位は0.001pt。配分は切り捨てた後、小数部の大きい参加者から残りの単位を配る。同値の場合は参加者ID順。成功した占領1件につき設置と維持の合計は100pt。

総合貢献ptは、キル数×20 ＋ アシスト数×10 ＋ 設置貢献pt ＋ 維持貢献pt。デスは成績に表示する。チームのキル・占領・保有による得点と勝敗判定は既存のルールに従い、個人ポイントとは独立している。

## 通知とリザルト

撃破と占領完了の通知は最大5件。新しい通知が下に入り、5秒で消える。最後の1秒でフェードし、一時停止中は表示時間の経過も止まる。通知には参加者IDと拠点IDを使用し、正確な敵位置は表示しない。占領ゲージは現在の進行tickを参照する。

戦闘シミュレーションはラウンド番号、tick、連番付きでイベントを発行し、画面は同じイベントを一度だけ表示する。成績はラウンド終了時にスナップショットとして保存し、試合累計は参加者IDごとに整数単位で加算する。次ラウンドは空の成績から始まり、再戦は新しい試合として累計も初期化する。3ラウンド先取ではラウンド勝利数とチーム累計スコアを表示する。

将来の拡張候補は味方の回復、バリアによる吸収、スキル支援、中立モンスター討伐、防衛・妨害。既存のイベントと同様に、シミュレーションで確定できる条件を導入した時点で貢献に反映する。
