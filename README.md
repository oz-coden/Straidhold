# Straidhold

Straidholdは、[Simpludify](https://github.com/oz-coden/Simpludify)を使った見下ろし型5対5タクティカルアクションゲーム。協力PvEを中心に、将来のPvP、拠点占領、ラウンド制の対戦、キャラクター固有能力を組み合わせる構想がある。

**v0.2.3はブラウザで遊べる試作版。** プレイヤーは青チームの1人を操作し、味方AI4人と敵AI5人で拠点を奪い合う。拠点に占領装置を設置し、起動が完了するまで守ると所有権が移る。拠点を保持すると継続得点が入り、5分後に勝敗が決まる。

[ブラウザで試作版を開く](https://github.oz-coden.com/Straidhold/)

## 戦場を選ぶ

| 戦場 | 拠点数 | 特徴 |
| --- | ---: | --- |
| 両側分岐 | 7 | 上下の前進拠点から中央へ進む。中央を横断するジャングルが近道。 |
| 中央三拠点 | 7 | 互いに離れた三つの中央拠点へ、外周と中央の両方から接近できる。 |
| 中央防衛線 | 5 | 両陣営の前進拠点が、それぞれ中央の三拠点への補給を支える。 |
| 分岐と合流 | 4 | 前進拠点から上下に分岐し、中央や外周のジャングルでも迂回できる。 |
| 交差補給路 | 7 | 中央の接続点を経由して、上下のレーン間で補給をつなぎ替えられる。 |
| 試作演習場 | 3 | 従来の小規模戦場。 |

5つの戦術マップは5対5に合わせて縮小しており、全拠点は中立で始まる。選択した戦場で試合を開始し、結果画面から別の戦場を選び直せる。

## 戦場の見方

- カメラは自分に追従する。地形は最初から分かり、生存中の味方全員から見えない場所が暗くなる。
- ミニマップには地形・本部・拠点、味方、自分の向き、味方が視認中の敵、現在のカメラ範囲が出る。白い矢印は自分、丸は味方、ひし形は視認中の敵。
- 戦況HUDでは敵味方の生存人数、復活までの秒数、全拠点の所有・起動・係争状況を確認できる。拠点記号の ⇆ は本部に補給接続、× は所有したまま孤立している状態。ミニマップでは青の実線・赤の破線で有効な通路が分かる。
- 自軍の補給通路を進むと加速し、敵の有効な補給通路に深く入るほど減速する。ジャングルでは通常の移動速度になる。緑の茂みでは、敵が近づくか自分が攻撃するまで姿を隠せる。敵の位置や戦闘表示はチーム共有視界に従う。

## ローカルで遊ぶ

Node.js 24以上とnpmを用意する。

```sh
npm ci
npm run dev
```

表示されたURLを開き、戦場を選んで**試合開始**を押す。URLに `?round=20` を付けると20秒で終了する。短縮設定は5〜300秒の整数を受け付ける。

## 操作

| デバイス | 移動 | 照準と通常攻撃 | 占領装置の設置 |
| --- | --- | --- | --- |
| キーボード・マウス | WASD | マウスで照準、左クリックを押し続けて連射 | E |
| スマートフォン | 左側の仮想スティック | 右スティックを倒している間、指定方向へ攻撃。中心に戻すか離すと止まる | 「設置」をタップ |
| ゲームパッド | 左スティック | 右スティックで照準、右トリガー・右ショルダー・南ボタンで攻撃 | 西ボタン（XboxのX・PlayStationの□） |

- 右スティックがデッドゾーン内にある間は攻撃しない。固定モードでは、固定中心から離れた位置に触れた時点で方向が入力される。
- 白い輪が自分、オレンジの六角形が現在の攻撃対象。通常攻撃は射程・照準方向・遮蔽物で対象を絞る。
- 拠点の輪に入り、設置操作を行う。敵が輪に入ると起動が止まり、味方が誰もいない状態が続くと装置が消える。
- 通常シールドは被弾から3秒後に回復を始める。HPは自軍本部で回復でき、死亡後は自軍本部で復活する。
- スマートフォンは横画面推奨。タッチとマウス・キーボードの切り替えは、実際の操作に応じて行う。ゲームパッドはブラウザが標準マッピングとして認識する機種に対応する。
- **操作設定**で入力方式を固定し、左右それぞれのスティックを固定・浮動・追従から選べる。大きさ、透明度、デッドゾーンは左右共通。設定はブラウザに保存される。設定を開いている間は試合が一時停止する。

## 開発と検証

```sh
npm run check
npm test
npm run build
npx playwright install --only-shell chromium
npm run test:browser
npm run simulate
```

`dist/` はサブパス配信にも対応する静的ビルド。自動ブラウザ検証はChromiumを対象とし、スマートフォンとゲームパッドはエミュレーションを使用する。
