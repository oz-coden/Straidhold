# v0.2.1 戦場縮小と戦闘テンポ

5対5向けの戦場を縦横約半分に再設計した。拠点ID・補給グラフ・初期中立状態を引き継ぎ、壁と茂みをタイル単位で置き直した。レーンは幅4タイルで、占領領域（半径54）を避けて壁を配置し、両外周にジャングル経由の横断経路を確保した。基礎移動速度151、当たり判定半径12、攻撃射程165、視界235はv0.2.0と共通。旧演習場を含め6戦場を選択できる。

- 両側分岐は上下の前進拠点を広げて、中央のジャングルに壁を避けて抜ける経路と茂みを残した。
- 中央三拠点は中央の拠点間隔を15タイル取り、分散して占領する余地を残した。上側のジャングルを回って外の拠点にも接近できる。
- 中央防衛線は前進拠点から3方向に進める。中央路脇の壁と茂み、下側外周の迂回を用意した。
- 分岐と合流は上下2レーンの間に、拠点のない中央の迂回と茂みを配置した。
- 交差補給路はA–B–Cの補給リンクを保持した。中央の壁と茂みの間を抜けて、中央リンクを持つ側の補給を切りに行ける。
