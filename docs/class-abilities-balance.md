# v0.4.0 ヘッドレスAI戦

`npm run simulate` は、各戦術マップで60Hzの5分戦を8通り実行し、1戦ごとのJSONを出力する。引数にマップIDを渡すと、そのマップだけを計測できる。試合開始からの初発射時刻、射撃間隔、交戦秒数、占領、撃破、チーム別・クラス別の発動成功数を記録する。

標準編成は各チーム5クラスを1人ずつ割り当てる。標準編成はシード0・2の同戦略、シード1の側面戦略対中央戦略とその陣営入れ替えを試す。追加計測はシード3のソロ用タンク編成とその陣営入れ替え、シード4のアサシン2人編成対サポート2人編成とその陣営入れ替え。交戦秒数は最後の発射から3秒以内のtickを合算する。発射には、同tickの先行着弾で無効になったものも含む。

## 標準編成の比較（20戦）

| 指標 | v0.3.4 | v0.4.0 |
| --- | ---: | ---: |
| 青勝／赤勝／引き分け | 9／11／0 | 8／8／4 |
| 撃破数 | 973 | 690 |
| 発射数 | 42,953 | 44,711 |
| 占領完了数 | 1,004 | 754 |
| 平均点差 | 169.4 | 124.5 |
| 平均の初発射時刻 | 9.71秒 | 9.61秒 |
| 平均交戦秒数 | 282.2秒 | 279.2秒 |

v0.4.0で発射数は増え、撃破数は減った。軽減・特殊バリア・肩代わりで同数の射撃に対して撃破が起きにくくなり、回復まで持ちこたえる場面がある。横移動の修正後は両チームが同じ条件で進んで競合する時間もあり、標準編成に同点が4戦発生した。

横移動は、進行方向に対する左右の符号を反転して対称な指令を出す。補正前の計測では標準編成20戦が青6勝・赤14勝だった。補正後は青8勝・赤8勝・4分となったため、クラス能力の基礎値を維持した。ひとつの戦場や編成での勝率には試行数が限られる。

リコンは混戦になる前にも発動できる。タンクとサポートは射程内の危険な味方を要し、CDも35秒で、成功回数は自己発動や地点指定より少なかった。これらの計測はAI初期戦略での傾向で、人間が操作した場合のクラス間の勝率は別途検証する。
