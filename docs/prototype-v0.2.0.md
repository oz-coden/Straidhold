## 補給接続

各チームの本部から、自軍所有の拠点だけをたどって接続済みの拠点を求める。両端が同じチームの接続済みノードである通路に、そのチームの速度効果が発生する。装置の設置・妨害と所有は独立しており、接続は起動完了で所有権が変わった時点に更新する。孤立した拠点は所有と得点を維持する。地形はいつでも通行できる。

- 自軍通路を移動すると、2.4秒かけて最大28%加速する。被弾すると加速が途切れ、1.5秒間は再加速できない。通路外へ出ると加速は解除される。
- 敵通路では、敵の接続済み最前線から通路に沿って進んだ最短距離に比例して減速する。46タイル分で最大24%に達する。分岐・交差では別経路も考慮する。通路を離れると残留減速は最大1.6秒で消える。ジャングルを歩いている間は通常速度で、残留効果だけが時間で消える。
- 本部復活・本部回復は従来のルールを使う。前線復活、修理、仮設設備、帰還テレポートはゲームデザイン上の今後の機能。

## ジャングル・茂み・AI

レーン外の通行可能な地形をジャングルとする。視認には既存の視界半径とSimpludifyのタイルレイキャストが必要。茂みにいる敵には、同じ茂みに入る、48ワールド単位以内に近づく、相手が実際に攻撃してから1.5秒以内のいずれかの探知条件も必要。どの場合も壁が視線を遮る。地形を表示するFogの明るさと、茂みの敵を描く条件は独立している。戦場、ターゲットマーカー、耐久、弾道、ミニマップに共有視界を適用し、攻撃とAIの索敵には各ユニット自身の視認が必要。

AIは戦場ごとの前進ルートをもとに、本部につながる拠点の確保と未接続の前線の攻略を行う。一部はジャングルを通り中央へ直接向かう。壁を回避する経路探索と低耐久時の本部への後退は引き続き利用する。

## ヘッドレス検証

```sh
npm run simulate --silent
npm run simulate --silent -- cross-supply
```
